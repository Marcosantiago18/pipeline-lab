# pipeline-lab

[![CI](https://github.com/Marcosantiago18/pipeline-lab/actions/workflows/ci.yml/badge.svg)](https://github.com/Marcosantiago18/pipeline-lab/actions/workflows/ci.yml)

Práctica de GitHub Actions y GitHub Pages: aplicación web de estadísticas de
notas (media, mediana y porcentaje de aprobados) con un pipeline de CI/CD.

## Documentación

- [docs/PIPELINE.md](docs/PIPELINE.md) — diagrama, tabla de workflows e incidencias del pipeline.

## Scripts

- `npm run dev` — servidor de desarrollo.
- `npm test` — pruebas con el ejecutor integrado de Node.
- `npm run lint` — análisis estático con ESLint.
- `npm run build` — compilación de producción.
